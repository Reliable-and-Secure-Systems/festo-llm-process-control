# Training Data Scenarios

The training dataset is generated across fourteen operating scenarios covering normal, critical, and recovery conditions for the dual-tank level and temperature system.

| Scenario | Condition |
|---|---|
| Temperature maintenance | Level normal, temperature within target band |
| Level critical low | Level severely below target |
| Level below target | Level moderately below target |
| Level control band | Level near target |
| Level above target | Level moderately above target |
| Level high drain | Level severely above target |
| Temperature cold start | Temperature far below target |
| Temperature warming | Temperature approaching target from below |
| Temperature overshoot | Temperature exceeding target from above |
| Temperature extreme | Temperature far outside target band |
| Critical both | Level and temperature both critical |
| Level ok, temperature bad | Level on target, temperature off target |
| Temperature ok, level bad | Temperature on target, level off target |
| Float switch edge | Level near the float switch cutoff boundary |
